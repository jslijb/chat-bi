version: 1.0.0
description: requirement-diff-analyzer 输出的标准变更影响报告模板

---

## 报告基本信息

| 字段 | 说明 |
|------|------|
| 报告编号 | {类型}-{年份}-{序号}，如 REQ-DIFF-2026-001 |
| 旧需求编号 | 变更前的需求编号 |
| 新需求编号 | 变更后的需求编号 |
| 报告状态 | 草稿 / 已确认 / 已应用 / 已废弃 |
| 生成时间 | YYYY-MM-DD HH:mm |
| 分析师 | AI / 用户名 |

---

## 变更类型定义

| 类型 | 代码 | 说明 |
|------|------|------|
| 新增 | ADD | 新增字段、指标、维度、表 |
| 修改 | MOD | 修改口径、类型、默认值 |
| 删除 | DEL | 移除字段、指标、维度、表 |
| 重构 | REF | 重命名或逻辑调整但语义不变 |

## 字段对比规则

### 字段名变更
```markdown
| 旧字段名 | 新字段名 | 变更类型 | 说明 |
|----------|----------|----------|------|
| old_name | new_name | 重构 | 字段重命名，逻辑不变 |
```

### 口径变更
```markdown
| 字段名 | 旧口径 | 新口径 | 变更类型 |
|--------|--------|--------|----------|
| 续保率 | 续保保单数/到期保单数 | 续保保单数/应续保保单数 | 修改 |
```

### 数据类型变更
```markdown
| 字段名 | 旧类型 | 新类型 | 影响评估 |
|--------|--------|--------|----------|
| amount | INT | BIGINT | 向后兼容，需DDL修改 |
```

---

## 影响等级定义

| 等级 | 符号 | 说明 | 影响范围 |
|------|------|------|----------|
| 严重 | S | 可能导致数据错误或系统故障 | 多个下游表/ETL/报表 |
| 高 | H | 需要较大改动，可能影响部分功能 | 1-2个下游表/ETL |
| 中 | M | 需要修改，但影响可控 | 单个表/ETL |
| 低 | L | 几乎无影响，仅需备注 | 仅配置变更 |

## 测试验证清单

### 数据正确性验证
- [ ] 新增字段数据分布符合预期
- [ ] 修改字段的新旧数据差异在合理范围
- [ ] 删除字段确认无下游依赖

### ETL回归测试
- [ ] 上游ETL执行成功
- [ ] 目标表数据更新成功
- [ ] 关键指标值与预期一致

### 报表验证
- [ ] 相关报表可正常刷新
- [ ] 图表展示无异常
- [ ] 数据下钻功能正常
