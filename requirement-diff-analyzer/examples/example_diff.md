## 示例一：保险行业 - 续保率口径变更

### 输入

**旧需求 REQ-001 v1.0：**
```markdown
# 续保率统计需求

## 指标定义
- 续保率 = 续保保单数 / 到期保单数

## 涉及表
- ods_policy_renewal (续保明细表)

## 维度
- 时间：月
- 产品类型：车险/家财险/意外险
```

**新需求 REQ-001 v2.0：**
```markdown
# 续保率统计需求（修订版）

## 指标定义
- 续保率 = 续保保单数 / 应续保保单数
- 口径说明：应续保 = 到期前30天内已续 + 到期未续 + 到期超30天未续

## 涉及表
- ods_policy_renewal (续保明细表)
- ods_policy_cancellation (保单注销表)

## 维度
- 时间：月/周
- 产品类型：车险/家财险/意外险/责任险

## 新增指标
- 续保流失率 = 流失保单数 / 应续保保单数
```

### 输出（变更分析报告摘要）

```markdown
# 需求变更分析报告：REQ-001 v1.0 → REQ-001 v2.0

## 1. 变更摘要

| 变更类型 | 数量 | 说明 |
|----------|------|------|
| 新增字段/指标 | 2 | 续保流失率、应续保保单数分解 |
| 修改字段/指标 | 1 | 续保率口径变更 |
| 删除字段/指标 | 0 | - |
| 涉及表变更 | 1 | 新增 ods_policy_cancellation |

## 2. 详细变更列表

### 2.2 修改字段/指标

| 序号 | 字段名 | 旧口径 | 新口径 | 变更说明 |
|------|--------|--------|--------|----------|
| 1 | 续保率 | 续保保单数/到期保单数 | 续保保单数/应续保保单数 | 口径重大变更，需重新定义分母 |

## 3. 下游影响范围

| 类型 | 表名 | 影响说明 | 建议操作 |
|------|------|----------|----------|
| DWS | dws_policy_renewal_monthly | 续保率聚合字段需同步修改口径 | ALTER TABLE + 重跑历史数据 |
| ETL | etl_renewal_calc.sql:45 | 续保率计算逻辑需修改 | 更新 WHERE 条件和分母定义 |
| 报表 | 续保率监控看板 | 核心指标看板，需同步更新 | 刷新历史数据展示 |

## 4. 风险评估

| 风险项 | 风险等级 | 影响说明 | 缓解措施 |
|--------|----------|----------|----------|
| 历史数据回溯 | 严重(S) | 续保率计算口径变更，历史数据需重算 | 提前告知业务，保留v1版本数据1个月 |
| 报表数据抖动 | 高(H) | 口径变更后数据可能出现较大波动 | 沟通业务预期，做好数据解读 |

## 5. 建议操作清单

1. [P0] 修改 ods_policy_cancellation 表的 ETL 读取逻辑
2. [P0] 更新 dws_policy_renewal_monthly 的续保率口径
3. [P1] 修改 etl_renewal_calc.sql 第45行计算逻辑
4. [P1] 在测试环境运行完整回归测试
5. [P2] 通知业务方新口径上线时间

## 6. 业务确认

[ ] 已阅读变更分析报告
[ ] 确认续保率新口径定义准确
[ ] 确认历史数据回溯方案

**确认签名**：__________________
**确认日期**：__________________
```

## 示例二：电商行业 - 新增用户分层指标

### 输入

**旧需求 REQ-002 v1.0：**
```markdown
# 用户购买行为分析

## 指标
- 新客订单数
- 老客订单数
- 复购率

## 维度
- 月/周/日
- 渠道
```

**新需求 REQ-002 v2.0：**
```markdown
# 用户购买行为分析（扩展版）

## 新增指标
- RFM分层得分（R-最近购买天数、F-购买频率、M-购买金额）
- 用户生命周期价值（LTV）
- 用户活跃度分层（高活/中活/低活/沉默）

## 维度扩展
- 新增：用户等级（VIP/GOLD/SILVER/普通）
```

### 输出（变更分析报告摘要）

```markdown
# 需求变更分析报告：REQ-002 v1.0 → REQ-002 v2.0

## 1. 变更摘要

| 变更类型 | 数量 | 说明 |
|----------|------|------|
| 新增字段/指标 | 7 | RFM得分、LTV、活跃度分层、用户等级 |
| 修改字段/指标 | 0 | - |
| 删除字段/指标 | 0 | - |
| 涉及表变更 | 0 | - |

## 3. 下游影响范围

| 类型 | 对象 | 影响说明 | 建议操作 |
|------|------|----------|----------|
| DWS | dws_user_behavior_daily | 需新增RFM、LTV聚合字段 | CREATE TABLE 或 ALTER TABLE |
| ETL | etl_user_segments.py | 新增用户分层计算逻辑 | 添加 Python 数据处理逻辑 |
| 报表 | 用户价值分析看板 | 新增RFM矩阵图、LTV趋势图 | 新增页面组件 |

## 4. 建议操作清单

1. [P1] 在 dwd_user_trade 表中新增 R/F/M 原始字段
2. [P1] 在 dws_user_behavior_daily 中新增 RFM、LTV 聚合
3. [P2] 更新 etl_user_segments.py 添加分层逻辑
4. [P2] 在报表平台新增用户价值分析页面
```

3. **模板复用**：实际使用时，只需替换具体字段和表名
