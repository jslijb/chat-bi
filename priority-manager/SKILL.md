# 报表优先级管理引擎

## 技能描述
管理报表的优先级（P0/P1/P2/P3），实现自动升降级、依赖传播和归档恢复。

## 优先级定义

| 优先级 | 含义 | 执行窗口 | 资源队列 | 审批要求 |
|--------|------|---------|---------|---------|
| P0 | 核心领导报表 | 06:00-07:00 | production_high | A类领导审批 |
| P1 | 高频业务报表 | 07:00-09:00 | production | 业务方领导审批 |
| P2 | 常规报表（默认） | 09:00-12:00 | default | 无 |
| P3 | 低频报表 | 12:00-14:00 | low_priority | 无 |

## 自动升级规则

| 规则 | 条件 | 动作 | 限制 |
|------|------|------|------|
| 领导访问升级 | A类领导连续3天访问 | 升至P0 | 需A类领导审批 |
| 高频访问升级 | 30天日均访问>30次 | 升一级 | 最高P1 |
| 依赖传播升级 | 下游报表升级 | 上游同步升级 | 不超过下游级别 |

## 自动降级规则

| 规则 | 条件 | 动作 |
|------|------|------|
| 低频降级 | 30天无访问 | 降一级 |
| 长期闲置 | 60天无访问且为P3 | 归档 |
| 永久删除 | 365天无访问 | 永久删除 |

## 依赖传播

- **升级传播**：报表升级时，其上游DWS/DWD表同步升级（不超过报表级别）
- **降级检查**：报表降级时，检查是否有更高优先级的下游报表依赖，有则不降级

## 归档恢复

- 归档报表30天内被访问>=10次 → 恢复至P3
- 超过30天未恢复 → 永久删除

## 执行时机
异步，每日凌晨批量执行（由async-task-scheduler调度）
